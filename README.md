# บ้านบรู Dashboard

Dashboard ยอดขายของ “บ้านบรู” (Baan Brew) เครือร้านกาแฟสมมติ 5 สาขาในกรุงเทพฯ ทำเป็นงาน Lab 1 ของวิชา Basic Data Analytics & Visualization using AI Vibe Coding (คาบ 1 · 26 ก.ย. 2026)

เจ้าของร้านเปิดดูแล้วควรรู้ภายในไม่กี่วินาทีว่าเครือร้านไปได้ดีแค่ไหน และควรโฟกัสที่สาขาไหน ตัวเลขทุกตัวตรวจกับ Pivot Table ใน Excel หรือ Google Sheets ได้

## ฟีเจอร์

- **เลือกช่วงเวลาและสาขา:** 7 / 30 / 90 / 365 วันล่าสุด หรือทั้งหมด นับถอยหลังจากวันล่าสุดในข้อมูล และกรองเฉพาะสาขาได้
- **KPI 4 ตัว เทียบช่วงก่อนหน้าเป็น %:** ยอดขายรวม, จำนวนบิล, ยอดเฉลี่ยต่อบิล, ลูกค้าสมาชิก กดที่ KPI เพื่อสลับตัวที่แสดงในกราฟหลัก
- **กราฟแนวโน้ม:** ดูรายวัน รายสัปดาห์ หรือรายเดือน มีเส้นช่วงก่อนหน้าไว้เทียบ ถ้าดูรายวันในช่วงยาว จะมีเส้นค่าเฉลี่ย 7 วันให้ด้วย
- **ยอดขายแยกสาขา:** เรียงจากมากไปน้อย พร้อม % เปลี่ยนแปลง สาขาที่เลือกอยู่จะถูกไฮไลต์
- **เมนูขายดี 5 อันดับ**
- **ที่มาของตัวเลข:** กดที่ตัวเลขไหนก็ได้เพื่อดูแถวตัวอย่างจาก `sales.csv` สูตรสำหรับ Google Sheets / Excel ที่ใช้ตรวจตัวเลขนั้น และดาวน์โหลดแถวที่ใช้คำนวณเป็น CSV
- **ย้อนดูย้อนหลัง:** เล่นภาพเคลื่อนไหวยอดขายทีละสัปดาห์บนแผนที่สาขา ตั้งแต่ต้นจนจบข้อมูล

## เทคโนโลยี

React 19, Vite 7, Tailwind CSS 4, Recharts 3, PapaParse ข้อมูลเป็นไฟล์ CSV แบบ static ที่โหลดในเบราว์เซอร์ ไม่มี backend

## เริ่มใช้งาน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:5173

build สำหรับ deploy ด้วย `npm run build` (ไฟล์ที่ได้อยู่ใน `dist/`)

## โครงสร้างโปรเจกต์

| ที่อยู่ | เนื้อหา |
|---|---|
| `src/lib/metrics.js` | ตรรกะการคำนวณทั้งหมด (KPI, ช่วงเวลา, time series, สูตรสำหรับตรวจตัวเลข) แยกจากส่วนแสดงผล |
| `src/App.jsx` | โหลดข้อมูลและจัดวางหน้า Dashboard |
| `src/components/` | การ์ดแต่ละใบ (Trend, Branch, Top products, Replay) แผงที่มาของตัวเลข และ UI พื้นฐาน |
| `public/` | CSV ที่ Dashboard ใช้: `sales.csv`, `products.csv`, `branches.csv` |
| `data/` | ชุดข้อมูลเต็มของวิชา ใช้ในคาบถัด ๆ ไป (ดู [`data/README.md`](data/README.md)) |
| `PRODUCT.md`, `DESIGN.md` | เป้าหมายของผลิตภัณฑ์และแนวทางการออกแบบ |
| `PROMPTS.md` | Prompt ที่ใช้สั่ง AI ในแล็บ |

## นิยามตัวเลข

- 1 แถวใน `sales.csv` = 1 รายการสินค้า ไม่ใช่ 1 บิล (บิลหนึ่งมีได้หลายแถว)
- ยอดขาย = `qty × unit_price`
- จำนวนบิล = จำนวน `order_id` ที่ไม่ซ้ำ
- ลูกค้าสมาชิก = จำนวน `customer_id` ที่ไม่ว่างและไม่ซ้ำ (ช่องว่าง = ลูกค้าทั่วไป)
- วันที่ = 10 ตัวอักษรแรกของ `datetime` (เวลาไทย) ไม่แปลงผ่าน UTC

ข้อมูลครอบคลุม 1 เม.ย. 2025 – 20 ก.ย. 2026 มี 53,092 แถว, 34,791 บิล

## ติดปัญหาบ่อย

- **กราฟว่างหรือยอดเป็น 0:** ตัวเลขใน CSV ถูกอ่านเป็นข้อความ ต้องแปลง `qty` และ `unit_price` เป็น Number ก่อนคำนวณ
- **จำนวนบิลเป็น 53,092:** นับแถวแทนการนับ `order_id` ที่ไม่ซ้ำ
- **ยอดขายรายวันเลื่อนไป 1 วัน:** ใช้ `new Date(...).toISOString()` ซึ่งแปลงเป็น UTC ให้ใช้ 10 ตัวอักษรแรกของ `datetime` แทน
- **`npm install` ไม่ผ่าน:** ตรวจเวอร์ชัน Node.js แล้วลองลบ `node_modules` และติดตั้งใหม่
