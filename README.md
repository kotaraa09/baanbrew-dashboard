# บ้านบรู Dashboard

Dashboard ยอดขายของ “บ้านบรู” (Baan Brew) เครือร้านกาแฟสมมติ 5 สาขาในกรุงเทพฯ ทำเป็นงาน Lab 1 ของวิชา Basic Data Analytics & Visualization using AI Vibe Coding (คาบ 1 · 26 ก.ย. 2026)

เจ้าของร้านเปิดดูแล้วควรรู้ภายในไม่กี่วินาทีว่าเครือร้านไปได้ดีแค่ไหน และควรโฟกัสที่สาขาไหน ตัวเลขทุกตัวตรวจกับ Pivot Table ใน Excel หรือ Google Sheets ได้

## ฟีเจอร์

- **หัวเรื่องจากข้อมูล:** ประโยคเปิดหน้าภาพรวมเขียนจากตัวเลขจริงของช่วง/สาขาที่เลือก (ยอดขาย, % เทียบช่วงก่อน, สาขาที่นำ, เมนูทำเงินสุด, ชั่วโมงพีค)
- **เลือกช่วงเวลาและสาขา:** 7 / 30 / 90 / 365 วันล่าสุด หรือทั้งหมด นับถอยหลังจากวันล่าสุดในข้อมูล และกรองเฉพาะสาขาได้
- **KPI 4 ตัว เทียบช่วงก่อนหน้าเป็น %:** ยอดขายรวม, จำนวนบิล, ยอดเฉลี่ยต่อบิล, ลูกค้าสมาชิก มี sparkline ใต้ตัวเลข กดที่ KPI เพื่อสลับตัวที่แสดงในกราฟหลัก
- **กราฟแนวโน้ม:** ดูรายวัน รายสัปดาห์ หรือรายเดือน มีเส้นช่วงก่อนหน้าไว้เทียบ ถ้าดูรายวันในช่วงยาว จะมีเส้นค่าเฉลี่ย 7 วันให้ด้วย
- **ยอดขายแยกสาขา:** เรียงจากมากไปน้อย พร้อม % เปลี่ยนแปลง สาขาที่เลือกอยู่จะถูกไฮไลต์
- **เมนูขายดี 5 อันดับ:** แก้วเล็กข้างชื่อเมนูเติมกาแฟตามยอดขายเทียบกับอันดับ 1
- **เรื่องเล่า "ห้าสาขา คนละจังหวะ":** เปิดหน้าภาพรวมด้วยทุกบิลเป็นจุดหนึ่งจุด (ราว 35,000 จุดบน canvas) เลื่อนหน้าแล้วจุดชุดเดิมย้ายไปตอบคำถามทีละข้อ: แยกสาขา → ชั่วโมง → วันในสัปดาห์ → เดือน (สาขาอารีย์เปิด, มหาวิทยาลัยปิดเทอม) → วันหยุดนักขัตฤกษ์ ทุกตัวเลขในข้อความคำนวณจากข้อมูล
- **จังหวะของแต่ละสาขา:** ภูเขาซ้อน (ridgeline) ของ % บิลตามชั่วโมงทั้ง 5 สาขาเทียบค่าเฉลี่ยทั้งเครือ ชี้เพื่ออ่านค่าชั่วโมงเดียวกันทุกสาขา พร้อมตัวคูณยอดวันเสาร์–อาทิตย์และวันหยุดบนสเกล log
- **เมนูไหนทำเงินจริง:** วิศวกรรมเมนู ขายได้กี่ชิ้น × กำไรขั้นต้นต่อชิ้น (ราคา − ต้นทุนจาก products.csv) แบ่งเป็นดาวเด่น ม้างาน ปริศนา ตัวถ่วง
- **ปฏิทินคั่ว:** ยอดขายทุกวันในช่วง ยิ่งขายดียิ่ง "คั่วเข้ม" มีเครื่องหมายวันหยุดนักขัตฤกษ์ ช่วงสั้นแสดงเป็นปฏิทินแขวนผนัง ช่วงยาวเป็นแถบแบบ GitHub พร้อมยอดเฉลี่ยของแต่ละวันในสัปดาห์
- **นาฬิกากาแฟ:** ยอดขายตามชั่วโมงของวันบนหน้าปัด 24 ชั่วโมง สลับดูเป็นแก้วหรือยอดขายได้
- **ที่มาของตัวเลข:** กดที่ตัวเลขไหนก็ได้เพื่อดูแถวตัวอย่างจาก `sales.csv` สูตรสำหรับ Google Sheets / Excel ที่ใช้ตรวจตัวเลขนั้น และดาวน์โหลดแถวที่ใช้คำนวณเป็น CSV
- **ย้อนดูย้อนหลัง:** เล่นภาพเคลื่อนไหวยอดขายทีละสัปดาห์บนแผนที่สาขา ตั้งแต่ต้นจนจบข้อมูล
- **สองช่วงเวลาของร้าน:** ธีมสว่าง = เช้าที่บาร์ดริป, ธีมมืด = ค่ำในโรงคั่ว ภาพคั่นส่วนและสีของกราฟเปลี่ยนตามธีม กดสวิตช์แล้วธีมใหม่ขยายเป็นวงกลมออกจากจุดที่กด ถ้ายังไม่เคยเลือก จะเลือกตามเวลากรุงเทพฯ ตอนเปิดหน้า

### ภาพประกอบ

สร้างด้วย AI ผ่าน [fal.ai](https://fal.ai) (FLUX.2 Pro) แล้วบีบอัดเป็น WebP ไว้ที่ `public/media/` เป็นการตกแต่งล้วน ตัวเลขทุกตัวยังคำนวณจาก CSV สคริปต์สร้างอยู่ที่ `scripts/media/gen.mjs` (ต้องมี `FAL_KEY` ใน `.env`)

## เทคโนโลยี

React 19, Vite 7, Tailwind CSS 4, Recharts 3, d3-shape, Canvas 2D, PapaParse ข้อมูลเป็นไฟล์ CSV แบบ static ที่โหลดในเบราว์เซอร์ ไม่มี backend

## เริ่มใช้งาน

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:5173

build สำหรับ deploy ด้วย `npm run build` (ไฟล์ที่ได้อยู่ใน `dist/`)

ทดสอบ: `npm test` (unit test ด้วย Vitest รวม "truth check" ที่คำนวณตัวเลขในเรื่องเล่าซ้ำจากไฟล์จริงด้วยโค้ดแยก) และ `npm run test:e2e` (Playwright build แล้วเปิด production build ทั้งขนาดเดสก์ท็อปและมือถือ ตรวจทุกแท็บ เรื่องเล่า ภูเขาสาขา วิศวกรรมเมนู ตัวกรอง KPI ปฏิทิน ที่มาของตัวเลข Replay ธีม และต้องไม่มี error ใน console ครั้งแรกต้องติดตั้งเบราว์เซอร์ด้วย `npx playwright install chromium`) ภาพหน้าจอของแต่ละธีมอยู่ใน `e2e-results/screens/` วิธีตรวจตัวเลขในเรื่องเล่าด้วย Excel อยู่ที่ [`docs/VERIFY.md`](docs/VERIFY.md)

| `public/` | CSV ที่ Dashboard ใช้ (`sales.csv`, `products.csv`, `branches.csv`, `customers.csv`) และ `media/` ภาพ/โมเดลที่สร้างด้วย AI |
| `e2e/` | ทดสอบ end-to-end ด้วย Playwright (เดสก์ท็อป + มือถือ) |

| `data/` | ชุดข้อมูลเต็มของวิชา ใช้ในคาบถัด ๆ ไป (ดู [`data/README.md`](data/README.md)) |
| `PRODUCT.md`, `DESIGN.md` | เป้าหมายของผลิตภัณฑ์และแนวทางการออกแบบ |

## นิยามตัวเลข

- 1 แถวใน `sales.csv` = 1 รายการสินค้า ไม่ใช่ 1 บิล (บิลหนึ่งมีได้หลายแถว)
- ยอดขาย = `qty × unit_price`
- จำนวนบิล = จำนวน `order_id` ที่ไม่ซ้ำ
- ลูกค้าสมาชิก = จำนวน `customer_id` ที่ไม่ว่างและไม่ซ้ำ (ช่องว่าง = ลูกค้าทั่วไป)
- วันที่ = 10 ตัวอักษรแรกของ `datetime` (เวลาไทย) ไม่แปลงผ่าน UTC

ข้อมูลครอบคลุม 1 เม.ย. 2025 – 20 ก.ย. 2026 · Dashboard ใช้ `public/sales.csv` ที่ทำความสะอาดแล้ว (53,057 แถว, 34,773 บิล) ส่วน `data/sales.csv` ต้นฉบับมี 53,092 แถว, 34,791 บิล

## ติดปัญหาบ่อย

- **กราฟว่างหรือยอดเป็น 0:** ตัวเลขใน CSV ถูกอ่านเป็นข้อความ ต้องแปลง `qty` และ `unit_price` เป็น Number ก่อนคำนวณ
- **จำนวนบิลเป็น 53,092:** นับแถวแทนการนับ `order_id` ที่ไม่ซ้ำ
- **ยอดขายรายวันเลื่อนไป 1 วัน:** ใช้ `new Date(...).toISOString()` ซึ่งแปลงเป็น UTC ให้ใช้ 10 ตัวอักษรแรกของ `datetime` แทน
- **`npm install` ไม่ผ่าน:** ตรวจเวอร์ชัน Node.js แล้วลองลบ `node_modules` และติดตั้งใหม่
